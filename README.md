# Hand Gesture Control Interface

## Overview

A computer vision application that uses hand gesture recognition to enable contactless interaction with digital systems. The project leverages MediaPipe and OpenCV for real-time hand tracking and gesture detection.

## Features

- Real-time hand tracking
- Gesture recognition
- Contactless control interface
- Computer vision-based interaction

## Technologies

- Python
- OpenCV
- MediaPipe

## My Role

Designed and developed the gesture recognition workflow, integrated computer vision libraries, and implemented real-time gesture tracking.
